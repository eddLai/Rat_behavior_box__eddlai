## 0. 症狀

- 2026-06：壞的是**右邊 R（pin9）**，根因是 R 伺服自身 GND 裂焊，T18 用「R GND → Arduino GND 臨時線」繞過。
- 2026-10：**現在壞的都是左邊 L（pin10）**。
- 程式版本：[UART_left_right_dir_deter_v8_1.ino](../Arduino_UART_from_python/UART_left_right_dir_deter_v8_1/UART_left_right_dir_deter_v8_1.ino)
- 觀察：「兩邊一直壞其中一邊」不合理 → 壞的不是固定某一邊，而是**接地拓樸比較吃虧的那一邊**。

## 1. 排除：不是程式造成 L 過勞

| 地方 | 左 L | 右 R |
|---|---|---|
| Mode 3 手動模式 | 不會動 | 開門後一直通電撐住，直到按 `0` |
| 舊 Mode 2 站立模式 | 不會動 | 每 20–35 秒開 6 秒 |
| Mode 5 給水時間 | `reward_time_L = 150` | `reward_time_R = 450` |
| Mode 1 | 一直通電 | 一直通電 |

程式給 L 的負擔**比 R 輕**。如果是程式讓馬達過勞，應該是 R 先壞，所以 L 壞不是程式造成的。

（但程式仍有可改善處，見 §7。）

## 2. 根因推論：T18 讓 L 變成 R 回流電流的旁路

T18 之後，R 出力的電流（堵轉可達約 1A）路徑：

```
R GND → Arduino GND → ⚡ Arduino↔洞洞板 的裂焊點（有電阻）→ 洞洞板 → powerbank GND
```

裂焊點有電阻 → **Arduino GND 和 powerbank GND 之間出現壓差**（例如 1A × 0.5Ω = 0.5V）。
這個壓差剛好跨在下面這條路上，電流就從這裡鑽過去：

```
Arduino GND → pin10（PWM 大多時間是 LOW＝接地）→ L 訊號線 → L 伺服內部輸入電路 → L GND → 洞洞板 → powerbank GND
                                                         ▲
                                                 燒壞 L 的就是這條路
```

訊號線沒有任何限流電阻，旁路電流可以到幾十～上百 mA，慢慢燒壞 L 伺服的輸入電路，也可能傷到 pin10。

| 時期 | 接地狀況 | 壞的那邊 |
|---|---|---|
| T18 之前 | R 的地線裂焊 | R 不會動 |
| T18 之後 | R 的電流改走 Arduino GND，L 變成回流旁路 | L 壞 |

> 待確認：L 是否是在 T18 改線**之後**才開始壞？若是，推論可信度很高。

## 5. 零件規格的由來

### 330Ω（1/4W）：訊號線保護電阻，串聯在訊號線上
- **下限（故障電流）**：ATmega328P 每支腳絕對上限 40mA、建議 20mA 以下。地線完全斷掉時，最壞約 5V 跨在電阻上：
  - 220Ω → 22.7mA（邊緣）
  - **330Ω → 15.2mA ✅**
  - 470Ω → 10.6mA ✅
  - 若只是 0.5V 的地電位差：0.5V / 330Ω ≈ 1.5mA（原本可能幾十～上百 mA）
- **上限（訊號品質）**：
  - 分壓：伺服輸入阻抗約 10kΩ 以上 → 5V × 10k / (10k + 330) ≈ 4.84V，伺服大於約 2.5–3V 就認得是 HIGH。
  - 邊緣：τ = 330Ω × 約 100pF ≈ 33ns，伺服脈衝 1–2ms，差約 3 萬倍，不影響。電阻到幾 kΩ 才可能出問題。
- **功率**：最壞 (0.015A)² × 330Ω ≈ 0.075W，1/4W 約 3 倍餘裕。
- 可接受範圍：**220–470Ω**。330Ω 是中間值，也是 E12 系列的常見值。
- 電阻**不在電源路徑上**，伺服轉動的電流從紅線來，不經過它，不會讓馬達沒力。

### 1000µF / 16V 電解電容：並聯在 5V 和 GND 之間
- 作用：伺服啟動或堵轉的瞬間（約 0.5–1A），powerbank 和導線反應不及，電容就近補電流。並聯，**不會降壓**。
- 估算：ΔV = I × Δt / C，取 I = 1A、Δt = 0.1–0.2ms、允許 ΔV ≤ 0.2V
  - Δt = 0.1ms → C = 500µF
  - Δt = 0.2ms → C = 1000µF
- 經驗值：小伺服每顆 100–470µF，兩顆 → 1000µF 涵蓋並有餘裕。
- 太大（4700µF 以上）：插上 powerbank 的瞬間湧浪電流可能觸發過電流保護 → 備案用 **470µF**。
- 耐壓：抓工作電壓的 1.5–2 倍以上。6.3V 太緊（USB 可到 5.25V 加突波）、10V 最低可接受、**16V 推薦**（漏電小、壽命長）、25V 也可以只是比較大。
- **極性**：長腳（+）接 WAGO-5V，白色條紋（-）接 WAGO-GND。接反可能鼓起或爆開。
- 電容只補「瞬間」的缺口，**不能解決長時間堵轉**（那要靠調整角度，見 §7）。
- 可接受範圍：470–2200µF、10V 以上。

### 0.1µF（104）陶瓷電容：並聯在 5V 和 GND 之間
- 電解電容內部有電感，處理不了 MHz 等級的高頻雜訊（例如馬達碳刷火花）。陶瓷電容電感低，專門濾高頻。
- 0.1µF 是數位電路去耦合的標準值。沒有極性。
- 推薦順位第 3，屬於加分項，可以先不裝。

## 8. 施工與驗收步驟

**換新馬達前先診斷（不然新的也會再壞）**
1. **量地電位差**：現有接法、通電、讓 R 動或卡住時，量 **Arduino GND 腳 ↔ L 伺服 GND 腳**（DC 電壓檔）。小於 0.05V 正常；0.1V 以上或隨 R 跳動 → 證實 §2 推論。
2. **pin10 有沒有壞**：燒 [static_high_pintest.ino](../Arduino_UART_from_python/motor_test/static_high_pintest/static_high_pintest.ino)，`TEST_PIN = 10`，量 pin10 ↔ GND 應約 5V。
3. **伺服有沒有壞**：壞的 L 伺服接另一台 Arduino 跑 sweep，看會不會動。

**接線順序**
1. 全部斷電。
2. 拆掉 T18 的「R GND → Arduino GND」臨時線、R 的舊地線；洞洞板的 5V/GND 匯流不再接 powerbank。
3. WAGO-5V：powerbank 5V、L 紅、R 紅、C1(+)、C2。
4. WAGO-GND ★ 主：powerbank GND、L 棕、R 棕、Arduino GND-1、連接線；延伸 WAGO：連接線、C2-、C1(-)。
5. 麵包板：330Ω 跨在不同的兩排；pin10 → L、pin9 → R（**不要接反**）。
6. 麵包板 (-) 排：Arduino GND-2、USB-TTL GND、LED 負極 ×4。
7. USB-TTL TX → pin2。
8. 所有線用束線帶固定。

**驗收**
1. 先不接訊號線，只開 powerbank，量 WAGO-5V ↔ WAGO-GND ≈ 5V。
2. LED 負極 ↔ Arduino GND 斷電量要通；拔掉 Arduino ↔ ★ 那條線後，LED 負極 ↔ powerbank GND 應**不通**。
3. 跑 [servo_sweep_pintest.ino](../Arduino_UART_from_python/motor_test/servo_sweep_pintest/servo_sweep_pintest.ino)，pin9、pin10 各測一次，兩顆都要順順地掃。
4. 讓 R 動或卡住時，量 **Arduino GND ↔ L 伺服 GND** 小於 0.05V，且不跟著 R 跳動。
5. 燒回 v8_1，Mode 1 送 `M` 看左右 LED 都會閃 15 次；Mode 5 左右各給水幾輪都穩定。

## !!! 筆記 !!!

- **壞的不是固定某一邊，而是接地拓樸比較吃虧的那一邊。** 修好一邊的地線，如果只是把大電流改道到另一條路，就會換另一邊壞。
- **大電流和小訊號要分開走**：伺服的電流直接回 powerbank（★），LED/UART 的小電流直接回 Arduino，兩邊只靠一條線相連（星形接地）。
- **訊號線串電阻是保險**：平常幾乎沒作用，地線出問題時把電流限制住，伺服和 Arduino 的腳都不會被燒掉。
